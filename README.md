## Descripción

Bioinformática, Genómica y Evolución Molecular es una asignatura teórico-práctica orientada al uso de herramientas computacionales para el estudio de secuencias biológicas, genes, genomas, transcriptomas, proteínas y procesos evolutivos.

A través de clases y actividades prácticas, el estudiantado aprende a consultar bases de datos biológicas, interpretar información genómica, comparar secuencias, utilizar herramientas bioinformáticas y diseñar estrategias de análisis aplicadas a problemas biológicos.

## Contenidos de este repositorio

Este repositorio reúne las clases y actividades prácticas correspondientes al módulo de **genómica, transcriptómica y análisis de datos de secuenciación masiva**

El módulo aborda los siguientes contenidos:

* Genómica y bases de datos genómicas.
* Transcriptómica y bases de datos de expresión.
* Navegación e interpretación de genomas.
* Fundamentos de la secuenciación masiva.
* Formatos de secuencias y archivos bioinformáticos.
* Control de calidad de datos de secuenciación.
* Alineamiento de lecturas contra un genoma de referencia.
* Cuantificación de la expresión génica.
* Fundamentos del análisis estadístico de datos transcriptómicos.
* Interpretación biológica de resultados de RNA-seq.

## Resultados de aprendizaje

Al finalizar el módulo, se espera que el estudiantado sea capaz de:

* Consultar y analizar críticamente información contenida en bases de datos genómicas y transcriptómicas.
* Identificar genes, transcritos, proteínas y variantes mediante sus identificadores.
* Interpretar la estructura y anotación de genes y genomas.
* Reconocer los principales formatos utilizados para representar secuencias, anotaciones y alineamientos.
* Describir las etapas fundamentales de un análisis de RNA-seq.
* Evaluar la calidad de datos de secuenciación masiva.
* Comprender los fundamentos del alineamiento y la cuantificación de secuencias.
* Aplicar herramientas estadísticas básicas al análisis de datos transcriptómicos.
* Interpretar los resultados bioinformáticos considerando sus alcances y limitaciones.
* Diseñar una estrategia de análisis para responder una pregunta biológica.

## Consideraciones para el uso del material

Las bases de datos y herramientas bioinformáticas se actualizan continuamente. Por esta razón, las actividades se concentran en la comprensión de los conceptos, la formulación de preguntas biológicas y la interpretación crítica de resultados, evitando depender exclusivamente de la ubicación de botones o elementos específicos de una interfaz.

Al utilizar los recursos del repositorio, se recomienda registrar:

* La fecha de consulta.
* La versión de la base de datos o programa.
* El ensamblaje genómico y la versión de la anotación.
* Los identificadores de genes, transcritos, proteínas o variantes.
* Los parámetros utilizados durante el análisis.
* Las decisiones adoptadas y sus fundamentos.
