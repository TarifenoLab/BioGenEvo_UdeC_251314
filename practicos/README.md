# Actividades prácticas

En esta sección se encuentran las actividades prácticas correspondientes al módulo de **genómica, transcriptómica y análisis de datos de secuenciación masiva**.

Cada práctico incluye actividades guiadas, preguntas de interpretación y ejercicios de aplicación orientados al análisis de problemas biológicos.

## Recomendaciones generales

Durante el desarrollo de las actividades:

- Registra la fecha de consulta y las versiones de las bases de datos utilizadas.
- Conserva los identificadores de genes, transcritos, proteínas y variantes analizados.
- Documenta los parámetros y decisiones adoptados.
- Diferencia los resultados observados de las interpretaciones biológicas.
- Considera las limitaciones de las herramientas y fuentes de información.
- Guarda una copia ordenada de los archivos generados.
